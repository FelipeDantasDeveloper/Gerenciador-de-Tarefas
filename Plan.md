#Projeto: To-do list simples com HTML, CSS E JavaScript

Este projeto coincide em um gerenciador de tarefas, é um projeto de tela única, onde na parte superior da tela teremos um campo de digitação para adicionar uma tarefa nova e um botão de envio.

Ao enviar a tarefa, ela será adicionada a uma lista exibida logo abaixo desse campo de texte.

As tarefas serão armazenadas em um array no próprio javaScirpt, sem uso de nenhuma ferramenta ou sistema externo.

Cada tarefa:

- Texto
- Boolean confirmando se está feita ou não

Sobre as ações possíveis em cada tarefa:
- Marcar ela como concluída, daí o texto fica riscado(via classe css).
- Deletar uma tarefa, então ela some da lista completamente.
- Adicionar uma tarefa nova através de um campo de texto na parte superior da tela que será sempre selecionada com o boolean de confirmação em false.

O projeto será feito utilizando HTML, CSS E JavaScript simpels.

No JavaScript, trabalhar sempre com EventListener e não adicionando eventos no HTML diretamente.
No início do JavaScript, já selecione em variáveis todos os elementos que serão manipulados.

Interface gráfica:

 - O fundo do projeto será cinza claro.
 - Tanto o campo quanto a lista ficarão em cards separados, com fundo branco, borda arredondada e uma leve separação entre os cards

A cor predominante para os botões(como o botão de adicionar e deletar ) será verde escuro.
